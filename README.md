# 独立积分历史插件

`dsh-credit-history` 是独立的 dsh 插件，页面入口为右侧边栏的 **积分历史** Tab
（由 `dsh-better-sidebar` 提供）。旧版本在 **设置 → 积分历史** 注册的入口已在
本次迁移中删除，设置页不再保留副本：数据只有一个显示位置。
它依赖 Jet Hub 提供的账号与只读余额协议，但不修改 Jet Hub 的 RPC、界面、
手动刷新、登录、签到或上下文设置。停用或卸载本插件不会改变 Jet Hub。

## 界面

- 图表优先：大面积余额走势图占满侧栏剩余高度，最新余额与区间净消耗压缩为一行摘要。
- 走势图按真实像素宽度绘制（`ResizeObserver` 自适应窄栏），悬停任意位置显示该时刻
  余额与区间变化；轴标签在跨日时自动带日期，避免 `06:40 → 00:47` 这类歧义。
- 折线按区间语义分段着色：蓝色为可估算的消耗，橙色为充值／周期重置等非消耗变动。
  间隔过长的 `gap` 处折线与面积**真的断开**并留一条琥珀色虚线标记，采样失败处留红色
  标记，都不会把一段空缺伪装成连续下降。只剩单个孤立有效采样时只画点、不画线。
- y 轴纵域按**观测到的波动幅度**留白，而不是按余额绝对值：账户持有 1,286 分、实际只
  波动 4 分时，走势依然填满高度（否则会是一条毫无信息的直线）。左侧刻度留白随最宽
  标签自适应，余额很大时自动改用「万／亿」，不会被画布裁掉数字。
- 「最近 12 次采样明细」默认折叠，需要时展开。
- 后台采样开关与采样间隔（5／15 分钟）收进该 Tab 自己的齿轮「功能设置」，
  数据仍写入插件后端状态，不在侧边栏偏好里保存第二份副本。

- 自动采样默认 15 分钟，可选 5 分钟，支持暂停。后台按来源和账号串行执行。
- 自动采样之间共享冷却状态，账号之间等待 2 秒；失败后最多退避到 60 分钟。
- Jet Hub 的手动查询保持原始行为，没有本插件附加的冷却、缓存或等待。
  上游平台本身的限流仍由它们的接口决定。
- 切换或关闭该 Tab 后继续采样，退出 dsh 后暂停；面板每 30 秒只读本机历史。
- 每个 API 源和账号分别显示余额与相邻采样的净消耗估算，历史保留 30 天。
- 失败、长断点、跨日和资源包变动不冒充消耗；充值和赠送会影响净消耗估算。

数据保存在 `$DSH_HOME/credit-history/history.json`，当前为
`C:/Users/qq/.dsh/credit-history/history.json`。
第一次启用会自动迁移旧合并补丁的 `$DSH_HOME/jet-hub/credit-history.json`，
保留全部采样记录与设置，也保留旧文件。
记录不含 API 密钥、token 或完整凭据。

本次迁移只改客户端半边（`client-src/` 与构建产物 `client.js`），后端采样、
RPC 与数据文件格式均未改动。重建客户端：

```powershell
$env:DSH_HISTORY_BUILD_TOOLS="C:\Users\qq\Documents\merchant\dsh-codearts-history-build\node_modules\esbuild"
node build-client.mjs
```

`client.js` 由 `dsh-client-hmr` 每 500ms 轮询，重新构建后浏览器热更新，
不需要重启 dsh。

安装：

```powershell
dsh plugin --profile web add "link:C:/Users/qq/Documents/merchant/dsh-credit-history" --ignore-scripts
```

验证：`node --test tests/*.test.mjs`（21 项，含走势图边界态与断点语义的回归锁）。
真实浏览器验收（需 dsh GUI 正在运行）：`cd verify; node accept.mjs`、`node verify/gear.mjs`。

协议适配使用已安装 `dsh-codearts-auth 0.1.0` 的内部只读余额函数，升级该依赖后需复核。

## 已知取舍

- 轴刻度优先用完整千分位数字（无歧义）；只有当最宽标签超出画布宽度的 45% 时才退回
  「万／亿」紧凑单位。紧凑单位在极大余额下可能让相邻刻度显示成同一个数，因此该回退
  只在必要时启用。
- 走势图不自动轮询历史以外的任何接口；面板在 Tab 可见且页面未隐藏时每 30 秒读一次
  本机历史文件。
